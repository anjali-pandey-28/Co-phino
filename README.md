# Co-phino

☕ Coffee Website.

A beautifully designed Coffee Shop Website built using HTML, CSS, and JavaScript.
This website highlights the warmth and aroma of a perfect coffee experience with smooth animations, elegant design, and responsive layouts.

 Features :-

 Home Section – Eye-catching hero banner with tagline and call to action.

 About Section – Shares the story, passion, and craftsmanship behind the coffee.

 Menu Section – Showcases a variety of coffee items with names, images, and prices.

 Testimonials Section – Displays real customer reviews and ratings.

 Gallery Section – A visual showcase of the café, drinks, and ambiance.

 Contact Section – Includes a contact form, social links, and location map.

 Responsive Design – Works seamlessly on desktops, tablets, and mobile devices.

 Interactive UI – Smooth scrolling, animations, and hover effects for a modern experience.

🛠️ Technologies Used

HTML5 – For clean and semantic structure

CSS3 – For layout, responsiveness, and animations

JavaScript (Vanilla JS) – For dynamic content and interactivity
